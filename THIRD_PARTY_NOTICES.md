# Third-party dependencies

This package calls APIs from Unity, VRChat SDK, Modular Avatar/NDMF, lilToon, VRCFury and DressingTools/DressingFramework. Install them separately under their respective licenses. Their source code and paid product assets are not included here.

Booth products and audio are imported by each user. Asset copies and mesh/controller derivatives are generated only inside the user's project and are not part of this distribution.

The documented lilToon 2.3.2 workaround identifies three inactive include comments; the third-party shader file is not redistributed.

See `Documentation~/BOOTH_ASSETS.md` for the draft product inventory and `Documentation~/COMPATIBILITY.md` for dependency versions.
