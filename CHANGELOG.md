# Changelog

## 0.2.0-preview.1

- Made user-selected A/B outfit bindings the default core workflow, with no fixed clothing names or required wings/Plum body masks.
- Added explicit binding API, setup window, range fitting, and preflight checks for overlapping groups, unsupported materials, and destructive body rules.
- Split optional Plum, DressingTools, wing, and simplified material-conversion adapters from core defaults/dependencies.
- Preserved halo timings and complementary scan; optional audio retains forward-only 0.7-second lead and volume 0.65.
- Retained external purchased Angelring Halo integration; no product assets are distributed and creator authorization remains pending documentation.
- Added bilingual core/adapter documentation and preserved historical validation/Plum inventory separately.
- Tested in isolated scenes; original backup scene and transformation resources preserved.

## 0.1.0-preview.1

- Extracted configurable Editor generator from the author's working transformation setup.
- Added Plum binding/timing/body-mask preset without paid assets.
- Added source-preserving installation on an avatar copy, regeneration/update and scoped uninstall.
- Added strict preflight and local callback/material-reference validation.
- Preserved halo timing, complementary A/B scan, persistent wing materials and optional forward-only audio.
- Added Agent workflow, preparation/version matrix, draft Booth inventory and release allowlist audit.
- Source-visible preview; no open-source license granted yet. VCC listing and independent fresh-project reproduction remain future work.
